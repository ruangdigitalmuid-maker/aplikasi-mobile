# AbsensiSiswa (com.webapp.absensisiswa)

Dibuat dengan **Web2APK Studio Pro**.

## Cara Build File APK Tanpa Android Studio (GitHub Actions)
1. Buat repositori baru di GitHub.com.
2. Upload seluruh isi folder ZIP ini (termasuk folder `.github/workflows/build-apk.yml`).
3. Buka tab **Actions** di GitHub, tunggu proses build selesai (±3 menit), lalu unduh file APK pada bagian **Artifacts**.
